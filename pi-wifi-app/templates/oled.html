Network IPs vs. Hotspot Details:
  • Network IPs: Lists all active adapters (eth0, wlan0). Can append the Hotspot IP dynamically.
  • Hotspot Details: Displays Hotspot SSID and Password. Option to auto-hide when a device connects.
Custom Page Variables:

Type these exact markers in any custom text line to inject live data onto the screen:

{time}   → 14:30:00
{date}   → 2026-09-20
{hour} / {minute} / {second}
{day} / {month} / {year}
{temp}   → 48.5
{web_port} → 8080
{wifi_ssid}→ Connected WiFi
{ap_ssid}  → Hotspot Name
{ap_pw}    → Hotspot PW
{ap_ip}    → Hotspot IP
